# lexorg

lexorg extracts the generalizable patterns I've been using for lexing PDF, Fortran, Markdown, ODB++ across the years.

Projects that use lexorg directly or already make use of these patterns:
- go-fortran: https://github.com/soypat/go-fortran
- piudf: https://github.com/soypat/piudf
- ohimark: https://github.com/soypat/ohimark
